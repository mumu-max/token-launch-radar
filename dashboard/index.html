The value model

implied value = TVL × category multiple × growth × maturity × distribution

The category multiple is calibrated from this snapshot: the median market-cap/TVL multiple of the live-token protocols in the same category (at least 3 comparables, else the whole-snapshot median of —). The median is used because one outlier protocol cannot move it; the table prints each category’s interquartile range so the spread is visible. Growth is the 7-day TVL change, clamped to −60…+120% and weighted by half, so it can move a value by at most −30% to +60% — a one-week spike can never dominate the ranking. Maturity rises with how long the protocol has run with no token, from 0.60 to 1.00 over three years. Distribution adds up to 10% for multi-chain reach. No protocol name is ever special-cased: the same function scores every row.

Method & limits

  • The board ranks 183 protocols: all 40 on the snapshot’s watchlist (TVL ≥ $50M, no token recorded) plus 143 pre-token protocols below the floor, by TVL.
  • Bridges, liquid-staking and restaking receipts, versioned pools (Name V2) and exchanges are not ranked: each is a product of a token that already trades, not a token that does not exist yet. The snapshot’s other protocols are the early ones the radar exists to find.
  • Farm plans are generated from each protocol’s own record — category, main chain, TVL, age — with the capital, gas and hold time the plan needs. Every plan states what counts as a qualifying action, an exit rule, and a risk check before claiming. They are a starting point, not financial advice; never pay to claim an airdrop, and claim only from the protocol’s own page.
  • Reach counts chains only. It says where a protocol runs, not who holds its token — the snapshot records no holder or governance data, so no concentration claim is made.
  • One watchlist protocol, USDD, is a stablecoin: its TVL is the outstanding supply, not user-locked value in the DeFi sense. It stays on the board because the competition’s watchlist requires every slug to be covered; the ranking follows the house’s list, not a claim that USDD is a protocol awaiting a token.
